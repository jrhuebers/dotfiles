# Selected-Cell Isolation Patterns (v64-v65)

These patterns emerged from the v64-v65 selected-cell isolation work under the gsd-supervisor.

## The Problem

When a benchmark function supports a `selected_cells` parameter for subset execution, ALL cells must be guarded - not just the target subset. The v64 error demonstrated this:

- Only VPD cells guarded with `should_run_cell`
- GASDE and VED cells ran unconditionally
- stdout showed 12 cells executed, not the declared 4
- This violated the "selected-cell isolation" contract

## The Fix: Guard ALL Cells

```python
def should_run_cell(cell_name, selected_cells):
    """Check if a cell should be run based on selected_cells filter."""
    if not selected_cells:  # Empty list means run all
        return True
    return cell_name in selected_cells
```

Then guard EVERY cell:

```python
# In run_metr_la_benchmark:
if should_run_cell("METR_LA_GASDE_MLP", selected_cells):
    print("\n--- Training GASDE MLP ---")
    mlp = DenoiserMLP(n_nodes=N, t_dim=64, hidden=256)
    mlp = train_model(mlp, train_loader, sde_gasde, L, device, epochs=epochs)
    results["METR_LA_GASDE_MLP"] = evaluate_model(mlp, sde_gasde, test_X, L, device, n_samples=n_eval_samples)
    print(f"  aMMD: {results['METR_LA_GASDE_MLP']['distance']['aMMD']:.4f}")

if should_run_cell("METR_LA_VPD_MLP", selected_cells):
    print("\n--- Training VPSDE MLP ---")
    mlp_vpd = DenoiserMLP(n_nodes=N, t_dim=64, hidden=256)
    mlp_vpd = train_model_vpsde(mlp_vpd, train_loader, sde_vpsde, L, device, epochs=epochs)
    results["METR_LA_VPD_MLP"] = evaluate_model_vpd(mlp_vpd, sde_vpsde, test_X, L, device, n_samples=n_eval_samples)
    print(f"  aMMD: {results['METR_LA_VPD_MLP']['distance']['aMMD']:.4f}")

if should_run_cell("METR_LA_VED_MLP", selected_cells):
    print("\n--- Training VESDE MLP ---")
    # ...VED MLP cell...

# Repeat for GNN, U-GNN, Transformer (12 total cells)
```

## Verification: Check stdout for Isolation

After running, verify ONLY selected cells appear:

```bash
grep "Training" stdout.txt

# --- Training VPSDE GNN ---

```

## Runner Integration vs Helper Path

The supervisor distinguishes between:

| Pattern | Description | How to Verify |
|---------|-------------|---------------|
| Helper-path smoke | Calling `train_model_vpsde()` and `evaluate_model_vpd()` directly | Works, but NOT runner integration |
| Runner integration | Calling the actual production benchmark function | Must call `run_metr_la_benchmark(selected_cells=[...])` |

**v65 correct pattern**:

```python
import joint_runner as jr
jr.seed_everything(42)  # Must come before any model instantiation

# Call actual production function
results = jr.run_metr_la_benchmark(
    device="cpu",
    epochs=1,
    n_eval_samples=2,
    selected_cells=["METR_LA_VPD_MLP", "METR_LA_VPD_GNN", "METR_LA_VPD_UGNN", "METR_LA_VPD_Transformer"]
)

# Verify all target cells present
for cell in target_cells:
    if cell not in results:
        print(f"ERROR: {cell} not in results!")
        sys.exit(1)
```

## Manifest Generation

The results JSON must be generated BY the script, not externally authored. The `executed_cells` must be mechanically derived from the returned results:

```python
# v65 correct pattern:
results = jr.run_metr_la_benchmark(...)

output = {
    "target_cells": target_cells,
    "executed_cells": list(results.keys()),  # Mechanical from actual results
    "model_results": {}
}

for cell in target_cells:
    if cell in results:
        res = results[cell]
        output["model_results"][cell] = {
            "status": "PASS",
            "aMMD": res.get("distance", {}).get("aMMD"),
            "QV_ref": res.get("reference", {}).get("QV"),
            "QV_gen": res.get("generated", {}).get("QV"),
            ...
        }

with open("v65_results.json", "w") as f:
    json.dump(output, f, indent=2)
```

## Summary Filter Bug

A common precedence bug in summary printing:

**v64 error**:
```python
if "VPD" in name and "MLP" in name or "GNN" in name or "UGNN" in name:
```
This matches non-VPD cells because `or` has lower precedence than `and`.

**v65 fix** - explicit membership:
```python
if name in target_cells:  # Explicit membership check
    ammd = res.get("distance", {}).get("aMMD")
    print(f"{name}: aMMD={ammd:.4f}")
```
